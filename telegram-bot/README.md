# 🤖 Приватный Telegram-бот «Семейный летописец»

Этот бот полностью решает проблему «лень открывать сайт»: вы и ваша девушка можете просто скидывать ему фото с подписями прямо в Telegram во время свиданий или поездок — бот сам сохраняет их в облако и выводит на сайт!

---

## ⚡ Быстрый старт за 2 минуты:

### Шаг 1. Создайте бота в Telegram
1. Откройте в Telegram бота [@BotFather](https://t.me/BotFather) и отправьте команду `/newbot`.
2. Введите имя для бота (например, `Наша История`) и юзернейм (например, `our_love_story_2024_bot`).
3. Скопируйте полученный **HTTP API Token**.

### Шаг 2. Узнайте свои Telegram User ID (для защиты от посторонних)
1. Вы и ваша девушка откройте бота [@userinfobot](https://t.me/userinfobot) в Telegram.
2. Он пришлет ваш цифровой `Id` (например, `123456789`).
3. Запишите ваши два ID через запятую.

### Шаг 3. Настройка файла .env
1. В папке `telegram-bot` создайте файл `.env` (скопировав `.env.example`).
2. Вставьте ваши данные:
   ```env
   TELEGRAM_BOT_TOKEN=ваш_токен_от_BotFather
   ALLOWED_USER_IDS=ваш_id,id_девушки
   SUPABASE_URL=ваш_проект_supabase
   SUPABASE_KEY=ваш_ключ_supabase
   ```

### Шаг 4. Запуск бота
Выполните в терминале в папке `telegram-bot`:
```bash
node bot.js
```

## ☁️ Бесплатный запуск 24/7 в облаке (без включенного ПК):
Бот можно бесплатно развернуть на:
* **Render.com** (Web Service или Background Worker) — бесплатно навсегда.
* **Railway.app**
* Либо через серверлесс **Supabase Edge Function** из папки `edge-function/` (вызывается Telegram вебхуком).
